# Pin Clutch with Pedal Actuation

## Overview

This project presents the design, analysis, and construction of a **Pedal-Actuated Pin Clutch**, developed as part of a Mechanical Engineering course project.

A Pin Clutch is a positive mechanical engagement system that transmits torque by inserting a pin into matching slots between rotating components. In this project, the engagement is controlled manually through a pedal mechanism, demonstrating the operating principles of mechanical power transmission, engagement, and disengagement.

The project combines mechanical design, CAD modeling, engineering calculations, manufacturing processes, and prototype validation into a complete engineering workflow.

## Features

* Mechanical pedal-actuated pin clutch mechanism
* Complete CAD design and assembly
* Kinematic analysis developed in Python
* Material selection and manufacturing process evaluation
* Physical prototype construction
* Force analysis
* Technical drawings and engineering documentation
* Functional validation of the mechanism
